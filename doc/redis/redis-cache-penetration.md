# 缓存穿透：布隆过滤器与缓存空值

> 主题边界：缓存三大经典问题系列之一——只讨论**查询不存在的数据**这一类穿透。姊妹篇：[redis-cache-breakdown.md](./redis-cache-breakdown.md)（热点 Key 过期）、[redis-cache-avalanche.md](./redis-cache-avalanche.md)（大量 Key 集中失效）。

---

## 1. 三大经典问题总览

| 问题     | 现象                              | 解决方案                                   |
|----------|-----------------------------------|--------------------------------------------|
| 缓存穿透 | 查询不存在的数据，绕过缓存直击 DB | 布隆过滤器拦截 + 缓存空值                  |
| 缓存击穿 | 热点 Key 过期瞬间大量请求涌入     | 互锁（Redisson 分布式锁）+ 逻辑过期        |
| 缓存雪崩 | 大量 Key 同时过期                 | 过期时间加随机值 + 多级缓存架构 + 缓存预热 |

三者的区分关键：**穿透**的数据根本不存在（缓存与 DB 都没有），**击穿**针对单个热点 Key 的过期瞬间，**雪崩**针对大量 Key 的集中失效。

## 2. 缓存穿透与布隆过滤器

缓存穿透指查询**不存在的数据**：缓存必然未命中，请求每次都直达 DB。若被恶意构造大量不存在的 Key 攻击，DB 会被无效查询压垮。

布隆过滤器（Bloom Filter）是一种空间效率极高的概率数据结构，用于快速判断元素**是否可能存在**。查询缓存前先经过布隆过滤器判断，若不存在则直接拦截，避免不存在的 Key 请求直达 DB。其判定语义是单向的：**判"不存在"一定准确，判"存在"可能误判**（哈希冲突所致），因此误判只会放行少量无效请求，不会误拦真实数据。

## 3. 方案一：Guava BloomFilter（单机场景首选）

Google Guava 库内置的布隆过滤器实现，API 简洁，适合单 JVM 内的防穿透场景。

```java
// 创建：预期插入 100 万个元素，误判率 1%
BloomFilter<String> bloomFilter = BloomFilter.create(
    Funnels.stringFunnel(Charset.defaultCharset()),
    1_000_000,
    0.01
);

// 数据缓存时写入布隆过滤器
bloomFilter.put("user:1001");

// 查询前先判断
if (bloomFilter.mightContain("user:1001")) {
    // 可能存在，查缓存 / DB
} else {
    // 一定不存在，直接拦截
}
```

- **优势**：使用简单、零额外依赖
- **局限**：不支持删除（标准布隆过滤器特性）；多实例间数据不共享，需各节点独立维护或同步副本
- **适用场景**：单机部署、可接受短暂数据不一致的业务

## 4. 方案二：RedisBloom（分布式场景首选）

Redis 官方模块，原生提供布隆过滤器能力，支持多个应用实例共享同一个过滤器，保证数据一致。

```bash
# 安装 RedisBloom 模块（Docker 方式）
docker run -p 6379:6379 redis/redis-stack:latest

# Redis CLI 操作
BF.ADD mybloom "user:1001"        # 添加元素
BF.EXISTS mybloom "user:1001"     # 判断是否存在，返回 1 = 可能存在，0 = 一定不存在
BF.RESERVE mybloom 0.01 1000000   # 预先创建：错误率 0.01，预期容量 100 万
```

- **优势**：分布式共享、支持动态扩容、支持持久化
- **局限**：需额外部署 RedisBloom 模块，增加运维成本
- **适用场景**：多实例部署、对数据一致性要求高的生产环境穿透防护

## 5. 兜底手段：缓存空值

布隆过滤器之外，对 DB 查询结果为空的 Key，也可将**空值**（如空对象或特殊标记）写入缓存并设置较短 TTL，使后续相同请求命中缓存而非反复打到 DB。实现极简，但会占用额外缓存空间，且空值 TTL 窗口内新增的真实数据可能短暂读不到，适合与布隆过滤器配合使用。
